GitHub Contact

Description

A command-line utility designed to download videos and music from multiple platforms and transfer them to your PS Vita using an optimized FTP workflow.

Features

Multi-source support
Download media from YouTube, SoundCloud, MEGA, and additional providers.
Automatic conversion
Converts media to PS Vita-compatible formats automatically.
FTP transfer
Sends files directly to your PS Vita via FTP.
Command-line interface
Ideal for use in NewTerm and other terminal applications.

Usage Examples

# Download and transfer a video psvmp "https://youtube.com/watch?v=example" --type video # Download and transfer music psvmp "https://soundcloud.com/artist/track" --type music # Show configuration psvmp --config-show # View download history psvmp --history

Dependencies

  • python3
  • ffmpeg
  • yt-dlp

Configuration

Set your PS Vita IP address and FTP port:

psvmp --config-set vita_ip=192.168.1.15 psvmp --config-set vita_port=1337
