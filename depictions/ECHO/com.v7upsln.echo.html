Description

A lightweight command-line system information tool for iOS that displays hardware and software details with clean, colorful terminal output.

Features

Device Information Displays device model and hardware specifications.
System Details Shows iOS/macOS version and kernel information.
CPU & GPU Specs Reports CPU brand, architecture, and GPU name.
Battery Monitoring Real-time battery percentage tracking.
System Uptime Shows how long the system has been running.
Storage & RAM Displays RAM capacity and storage usage statistics.

Usage

# Run Echo to display system information
echo

The tool will display comprehensive system information including device model, OS version, CPU, GPU, battery status, uptime, and storage details.

System Information Displayed

Device Model Hardware model identifier
OS Version iOS/macOS version information
Kernel Version System kernel details
CPU Information Brand and architecture
GPU Name Graphics processor details
Battery Status Current battery percentage
System Uptime Time since last restart
RAM Capacity Total memory available
Storage Info Capacity and availability

Platform Support

Echo is designed for macOS and iOS platforms, providing detailed system information in a clean terminal interface.
