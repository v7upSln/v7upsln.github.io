Description

A lightweight command-line system information tool for iOS that displays network details with clean terminal output.

Features

Wi-Fi Network Displays connected SSID, BSSID, and signal strength.
IP Addresses Shows local, public, and IPv6 addresses.
Network Interfaces Lists active interfaces such as Wi-Fi, Ethernet, and cellular.

Usage

# Run ipez to display network information
ipez

The tool will display comprehensive network information.

Platform Support

ipez is designed for macOS and iOS platforms.
